# Short Prompt

مولّد برومبتات احترافي للصور والفيديو والإعلانات والخط العربي، متاح كموقع وإضافة Codex.

## الموقع

https://turky015-oss.github.io/promptstudio/

## تثبيت إضافة Codex

أضف متجر الإضافة:

```bash
codex plugin marketplace add turky015-oss/promptstudio --ref main
```

ثم ثبّت Short Prompt:

```bash
codex plugin add short-prompt@turky-tools
```

بعد التثبيت، افتح مهمة جديدة في Codex واطلب برومبت تصوير أو فيديو أو إعلان أو خط عربي.
